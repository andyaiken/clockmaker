# Objectives

* This is an SPA which has two functions:
  * It allows the user to run an in-person game of Blood on the Clocktower using an iPad
  * It allows the user to build homebrew scripts with guidance

* Guiding principles:
  * Automate everything that can be automated, but always allow the user to break the rules
  * All character-specific logic will be codified in the character models; the logic will never know about specific characters
  * We are not beholden to the look and feel of the printed game
